# Odisha-only City autocomplete

The City fields keep their original **City** label and original element IDs. Their suggestions now contain Odisha district and block names, with type-ahead matching (for example, typing `K` shows names beginning with K). Existing database `city` fields and app workflows remain unchanged. Users can still type a local place manually if it is not listed.

Location options are based on Odisha's 30 districts and 314 blocks. The dropdown is a searchable suggestion list, not a complete village/street gazetteer.
